# Тренажёр звонков AllRight: что нужно настроить в ElevenLabs

Назар, привет! Это голосовой тренажёр для админов: админ звонит «маме» после пробного урока и отрабатывает скрытые возражения.

**Всё, кроме голоса, мы сделали сами:** сценарии, промпты, страницу для админов (этот репозиторий, GitHub Pages), приём результатов звонков (Google Apps Script → Google Таблица) и оценку по чек-листам (она живёт у нас отдельно).

От тебя нужна **одна разовая настройка одного агента**. Каждый месяц у нас около 12 новых сценариев, но трогать агента для них не нужно: страница передаёт промпт сценария через overrides при старте каждого звонка.

---

## 1. Создать одного агента

- **Название:** `AllRight Trainer — мама`.
- **System prompt и first message:** любые. Они переопределяются со страницы при каждом звонке.
- **LLM:** на твой выбор. Нужна модель, которая хорошо держит роль и говорит на украинском, румынском, польском, итальянском, английском, словацком, сербском и иврите. Промпты длинные (~6–9 тыс. символов) и с условной логикой: мама раскрывает настоящую причину только при определённых вопросах админа.
- **Языки агента:** украинский (`uk`), румынский (`ro`), польский (`pl`), итальянский (`it`), английский (`en`), словацкий (`sk`), сербский (`sr`), иврит (`he`). Если для override языка нужно, чтобы язык был в списке агента, добавь их все.
- **Максимальная длительность звонка:** 20 минут.
- **Перебивания:** разрешены, как в живом разговоре.
- **Evaluation criteria:** не нужны. Звонки оцениваем у себя по чек-листу каждого сценария.

## 2. Включить overrides (Security)

Включить переопределение для полей:

- **System prompt**
- **First message**
- **Language**
- **Voice** (TTS voice ID)

Без этого страница не сможет подставлять сценарии.

## 3. Голоса

Выбрать женский естественный голос для каждого языка: UA, RO, PL, IT, EN, SK, SR, HE. Голос взрослой мамы, спокойный, разговорный, не дикторский.

Пришли нам **Voice ID** для каждого языка. Мы впишем их в `config.js`.

## 4. Доступ к агенту

- Агент **публичный** (подключение по `agentId`, без signed URL). Серверной части у нас нет, это статическая страница.
- **Allowlist домена:** `<github-user>.github.io`. Точный адрес сообщим, когда опубликуем страницу. Так агентом нельзя будет пользоваться с других сайтов.

## 5. Инструмент «End call»

Включить у агента системный инструмент **End call** (`end_call`), чтобы мама могла сама положить трубку. Когда именно она это делает, описано в промпте каждого сценария: например, админ трижды давит на оплату, или разговор закончен и мама попрощалась. Настраивать условия в агенте не нужно, только включить инструмент.

## 6. Post-call webhook

После каждого звонка отправлять **post-call transcription webhook** на адрес нашего Google Apps Script. Адрес пришлём, он будет вида `https://script.google.com/macros/s/.../exec?token=...`.

Ключ уже стоит в самом адресе: Apps Script не видит заголовки запроса, поэтому HMAC-подпись проверить не сможет, и включать её не нужно. Аудио-webhook не нужен, только транскрипция.

В данных звонка обязательно нужны dynamic variables, которые страница передаёт при старте:

| Переменная | Что это |
|---|---|
| `admin_name` | кто из админов звонил (также передаётся как `userId`) |
| `scenario_id` | ID сценария, например `hidden-1` |
| `scenario_lang` | язык сценария: `ua`, `ro`, `pl`, `it`, `en`, `sk`, `sr`, `he` |
| `scenario_dept` | `sales` или `methodists` |

Плюс `conversation_id`, длительность и расшифровка.

## 7. Что прислать нам

- [ ] `agent_id`
- [ ] Voice ID для UA, RO, PL, IT, EN, SK, SR, HE
- [ ] Подтверждение, что overrides включены (prompt, first message, language, voice)
- [ ] Подтверждение, что инструмент End call включён
- [ ] Подтверждение, что webhook настроен (после того как пришлём URL)

## Как страница подключается (для проверки)

- SDK: `@elevenlabs/client@1.27.0`, IIFE-бандл с jsDelivr.
- Код в `index.html`, функция `startCall()`.

```js
ElevenLabsClient.Conversation.startSession({
  agentId,                       // из config.js
  connectionType: "webrtc",
  userId: adminName,
  overrides: {
    agent: { prompt: { prompt }, firstMessage, language },   // из сценария
    tts: { voiceId }                                          // из config.js по языку
  },
  dynamicVariables: { admin_name, scenario_id, scenario_lang, scenario_dept }
});
```
