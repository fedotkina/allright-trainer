# Тренажер дзвінків AllRight: що потрібно налаштувати в ElevenLabs

Назаре, привіт! Це голосовий тренажер для адмінів: адмін телефонує «мамі» після пробного уроку й відпрацьовує приховані заперечення.

**Усе, крім голосу, ми зробили самі:** сценарії, промпти, сторінку для адмінів (цей репозиторій, GitHub Pages), прийом результатів дзвінків (Google Apps Script → Google Таблиця) та оцінювання за чек-листами (воно живе в нас окремо).

Від тебе потрібне **одне разове налаштування одного агента**. Щомісяця в нас близько 12 нових сценаріїв, але чіпати агента для них не треба: сторінка передає промпт сценарію через overrides на початку кожного дзвінка.

## Контекст пілоту

- Зараз у тренажері **3 тестові сценарії** («Приховане заперечення 1–3»). На них перевіряємо, що все працює: голос, overrides, webhook, завершення дзвінка.
- Якщо все запрацює, **у листопаді тренажер проходитимуть усі адміни відділу продажів**. Сценарії мінятимуться й додаватимуться, але з нашого боку, без змін в агенті.
- Орієнтовне навантаження в пілоті: дзвінки по 10–15 хвилин, кілька сотень хвилин на тиждень. Можуть бути кілька дзвінків одночасно.

**Питання до тебе щодо навантаження:**
1. З якого акаунта / тарифу ElevenLabs списуватимуться хвилини і чи вистачить ліміту на листопад?
2. Скільки одночасних дзвінків дозволяє тариф? Нам важливо розуміти, чи можуть, наприклад, 5 адмінів телефонувати одночасно.

## 1. Створити одного агента

- **Назва:** `AllRight Trainer — мама`.
- **System prompt і first message:** будь-які. Вони перевизначаються зі сторінки під час кожного дзвінка.
- **LLM:** на твій вибір. Потрібна модель, яка добре тримає роль і говорить українською, румунською, польською, італійською, англійською, іспанською, словацькою, сербською та івритом. Промпти довгі (~6–9 тис. символів) і з умовною логікою: мама розкриває справжню причину лише за певних запитань адміна.
- **Мови агента:** українська (`uk`), румунська (`ro`), польська (`pl`), італійська (`it`), англійська (`en`), іспанська (`es`), словацька (`sk`), сербська (`sr`), іврит (`he`). Якщо для override мови потрібно, щоб мова була в списку агента, додай їх усі.
- **Максимальна тривалість дзвінка:** 20 хвилин.
- **Перебивання:** дозволені, як у живій розмові.
- **Evaluation criteria:** не потрібні. Дзвінки оцінюємо в себе за чек-листом кожного сценарію.

## 2. Увімкнути overrides (Security)

Увімкнути перевизначення для полів:

- **System prompt**
- **First message**
- **Language**
- **Voice** (TTS voice ID)

Без цього сторінка не зможе підставляти сценарії.

## 3. Голоси

Обрати жіночий природний голос для кожної мови: UA, RO, PL, IT, EN, ES, SK, SR, HE. Голос дорослої мами, спокійний, розмовний, не дикторський.

**Якщо для якоїсь мови немає голосу, що звучить природно** (або модель погано тримає цю мову), не підбирай «хоч якийсь». Просто напиши нам, які мови працюють добре, а які краще поки прибрати. Ми приберемо їх зі сторінки самі.

Надішли нам **Voice ID** для кожної мови. Ми впишемо їх у `config.js`.

## 4. Доступ до агента

- Агент **публічний** (підключення за `agentId`, без signed URL). Серверної частини в нас немає, це статична сторінка.
- **Allowlist домену:** `fedotkina.github.io`. Так агентом не можна буде користуватися з інших сайтів.

## 5. Інструмент «End call»

Увімкнути в агента системний інструмент **End call** (`end_call`), щоб мама могла сама покласти слухавку. Коли саме вона це робить, описано в промпті кожного сценарію: наприклад, адмін тричі тисне на оплату або розмову завершено й мама попрощалася. Налаштовувати умови в агенті не потрібно, лише увімкнути інструмент.

## 6. Post-call webhook

Після кожного дзвінка надсилати **post-call transcription webhook** на адресу нашого Google Apps Script. Адресу з ключем надішлемо окремо, вона має вигляд `https://script.google.com/macros/s/.../exec?token=...`.

Ключ уже є в самій адресі: Apps Script не бачить заголовків запиту, тому HMAC-підпис перевірити не зможе, і вмикати його не потрібно. Аудіо-webhook не потрібен, лише транскрипція.

У даних дзвінка обов'язково потрібні dynamic variables, які сторінка передає на старті:

| Змінна | Що це |
|---|---|
| `admin_name` | хто з адмінів телефонував (також передається як `userId`) |
| `scenario_id` | ID сценарію, наприклад `hidden-1` |
| `scenario_lang` | мова сценарію: `ua`, `ro`, `pl`, `it`, `en`, `es`, `sk`, `sr`, `he` |
| `scenario_dept` | `sales` або `methodists` |

Плюс `conversation_id`, тривалість і транскрипція.

## 7. Що надіслати нам

- [ ] `agent_id`
- [ ] Voice ID для UA, RO, PL, IT, EN, ES, SK, SR, HE
- [ ] Які мови краще поки прибрати, якщо такі є
- [ ] Підтвердження, що overrides увімкнені (prompt, first message, language, voice)
- [ ] Підтвердження, що інструмент End call увімкнений
- [ ] Підтвердження, що webhook налаштований
- [ ] Відповіді щодо хвилин і одночасних дзвінків (див. «Контекст пілоту»)

## Як сторінка підключається (для перевірки)

- SDK: `@elevenlabs/client@1.27.0`, IIFE-бандл із jsDelivr.
- Код в `index.html`, функція `startCall()`.

```js
ElevenLabsClient.Conversation.startSession({
  agentId,                       // з config.js
  connectionType: "webrtc",
  userId: adminName,
  overrides: {
    agent: { prompt: { prompt }, firstMessage, language },   // зі сценарію
    tts: { voiceId }                                          // з config.js за мовою
  },
  dynamicVariables: { admin_name, scenario_id, scenario_lang, scenario_dept }
});
```

2. Чи є обмеження щодо зберігання записів голосів працівників на боці ElevenLabs, про які нам варто знати?
