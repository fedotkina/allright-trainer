# Тренажёр звонков AllRight — страница для админов

Голосовой тренажёр: админ выбирает сценарий и звонит «маме» (агент ElevenLabs). Сценарии собираются в прототипе в claude.ai и публикуются кнопкой. Сервера нет: всё работает на бесплатных сервисах.

## Как всё связано

| Часть | Где живёт |
|---|---|
| Сценарии, чек-листы, оценка | прототип в claude.ai |
| Опубликованные сценарии | папка «Тренажёр звонков — сценарии» на Google Drive |
| Связка: отдаёт сценарии, принимает звонки | Google Apps Script (`apps-script/Code.gs`) |
| Звонки админов | таблица «Тренажёр звонков — звонки админов» |
| Страница для админов | GitHub Pages (этот репозиторий) |
| Голос и диалог | агент ElevenLabs (настраивает Назар, `NAZAR.md`) |

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | страница для админов |
| `config.js` | ID агента, голоса, адрес Apps Script |
| `scenarios.dat` | запасная копия сценариев, если Apps Script недоступен |
| `apps-script/Code.gs` | код скрипта-связки |
| `NAZAR.md` | что настроить в ElevenLabs (один раз) |

## Запуск (один раз)

### 1. Apps Script

1. Открыть [script.google.com](https://script.google.com) → **Новый проект**. Назвать «Тренажёр звонков».
2. Удалить всё в `Code.gs` и вставить содержимое `apps-script/Code.gs`. ID папки и таблицы уже вписаны.
3. Выбрать функцию `setup` и нажать **▶ Выполнить**. Разрешить доступ к Drive и Таблицам. В журнале появится ключ webhook.
4. **Развернуть → Новое развёртывание → Тип: Веб-приложение.** Запуск от имени: **Я**. Доступ: **Все**. Нажать «Развернуть» и скопировать адрес веб-приложения (заканчивается на `/exec`).
5. Адрес для Назара (webhook) — это адрес веб-приложения плюс `?token=` и ключ из журнала.

### 2. GitHub Pages

1. Создать репозиторий и загрузить эти файлы.
2. **Settings → Pages → Deploy from branch → main / root.** Адрес будет `https://<github-user>.github.io/<repo>/`.
3. В `config.js` вписать `scenariosUrl` — адрес веб-приложения Apps Script, **без** `?token=`.

### 3. Назар

1. Отправить ему `NAZAR.md`, адрес страницы (для allowlist) и адрес webhook с ключом.
2. Когда он пришлёт `agent_id` и Voice ID, вписать их в `config.js`.

## Новый сценарий (каждый раз, без Назара и без GitHub)

1. Собрать или поправить сценарий в прототипе.
2. На вкладке «Сценарии» нажать **«Опубликовать для админов»**.
3. Всё. Админы увидят новый сценарий при следующем открытии страницы.

Если публикация не сработала, кнопка «Скачать файл» скачивает `scenarios.dat`. Его можно загрузить в репозиторий вручную.

## Важно

- Файл сценариев зашифрован простым способом. Он защищает от случайного чтения, но не от человека с инструментами разработчика. Для внутренней тренировки этого достаточно.
- Ссылку на страницу давать только админам. Каждый звонок тратит минуты ElevenLabs.
- Если код Apps Script поменяется, нужно сделать **Развернуть → Управление развёртываниями → Изменить → Новая версия**. Адрес при этом не меняется.
